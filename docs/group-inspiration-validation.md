## 问题及复验历史

1. **GS-F01 / 已修复**：首轮全回归2690通过、1失败、20跳过。签名时效测试将时间设为未来121秒，只比120秒容差多1秒，传输跨秒可能使签名恢复有效。仅固定协议夹具的校验时钟，不改变产品签名规则；41项定向与2691项全量复验通过，独立审查确认不影响全局时钟或传输。
2. **GS-F02 / 夹具修正后通过**：本地Host测试首次控制器出现KeyError，另有Windows空设备写入被隔离审计拒绝。只修测试控制器/边界，保留初次失败记录；正式成功运行没有边界拒绝、没有清理产品历史来换取通过。
3. **GS-F03 / 检查器修正后通过**：首次在线检查误要求枚举schema为 `string`；SDK实际将 `Literal` 映射为 `select`。修正检查器，继续严格要求仅收藏默认及两个合法选项，58项self-test和实际Host查询通过，产品未改。
4. **GS-F04 / 维护环境修正后通过**：VPS系统Python3.10导入 `tomllib` 失败，预检尚未写入备份或切换记录。只读核实后改用现有Python3.13完成维护，没有安装生产依赖。一次只读进度查询的转义错误另行修正，未影响回归或生产状态。

完整日志、JUnit、图片、工作编号、数据库、配置及部署备份保留在维护环境，不进入仓库。公开JSON只收录显式筛选的计数、结果和代码/证据指纹；指纹用于对应私有原件，不代表原件可公开下载。
