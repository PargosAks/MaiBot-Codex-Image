# 小画师工作区

插件设置负责连接、启停、模型任务、授权和限额。任务、作品、评审和创作档案是小画师在运行中留下的记录，由插件自己的数据库保存。开启前仍须配置真实会话和持续委托，两层预算均须允许相应操作。

## 从计划到作品

小画师收到聊天灵感，或在定时唤醒时，可以创建计划、继续已有作品或等待。建立计划不等于已经生成图片。绘图成功后才有作品版本；看图评审可以接受当前图、保留旧最佳图，或建议在原图上细化。分享是下一项独立决定。

在支持 WebUI v2 的 MaiBot Dashboard 中打开「小画师」。先看当前空间的计划与预算，再查看作品版本、缩略图、评审及分享状态。页面读取的是已有记录；刷新不会排队绘图或向聊天发送图片。缩略图只是预览，不替代原图或评审证据。图片缺失或无法校验时不重新绘图补图。

在受托私聊中询问作品状态时，回复应依据当前会话能读取的账本摘要。计划存在、图片生成、Host 确认发送和 QQ 用户实际收图是不同的事实。发送结果未知时保留原意图和额度，不能通过查询、重载或重复分享来“验证”。

例如，在已授权私聊中问「现在在画什么？」或「鲸鱼娘画了吗？」。对于识别为单一状态询问的消息，插件不写入灵感队列，也不消耗小画师的思考、绘图或分享预算。普通对话回复仍由 MaiBot 的聊天模型生成，不保证逐字复述；包含追加绘画要求、附件或未识别的问法，仍走正常消息流程。摘要只包含当前作品和少量近期记录，未查到的旧作品应在工作区分页查看，不能据此断定没画过。

例如，委托人说「要不要按之前的角色设定画一张湖边散步的图？」时，小画师仍可自行决定是否采用。插件在这条消息确实写入灵感队列后，才把“已收到建议”的事实交给本轮私聊的规划和回复模型。它不会附带余额、档案版本、作品状态或服务诊断，也不会另发一条确认消息。自然回复由 MaiBot 的模型生成；如果想了解后续进度，可以问「现在在画什么？」或查看工作区。

回执只面向能明确识别的纯文字建议。带附件、混合问法或未识别的表达仍按原规则处理聊天灵感及获授权的参考图。没看到确认不等于入队失败，不需要重复发消息；可以稍后到工作区查看计划。

## 创作档案

档案描述想在多幅作品中保持的特征，例如角色轮廓、配色、画风和可变背景。小画师可以自行建档或更新版本，也可直接创作一次性主题。建档不是持续创作授权，不增加额度，也不直接调用绘图。已开工的作品继续使用立项时冻结的档案和系列版本。

已有安装保留插件身份、数据目录、MCP 绑定、原配置和全部历史记录。旧设置中的 `profiles` / `series` 用于兼容导入，新安装不需要手填。不要删除旧账本、换空间编号或恢复旧数据库来重试迁移。升级后应在工作区核对历史计划、版本与额度，再进行新的创作验收。

当前账本为 schema 9（schema 7 增加自主档案，schema 8 增加群念头采用关联，schema 9 增加独立群分享策略）。升级前在无在途操作时按一致性方式备份插件数据；不要让旧版写入新账本。回退需保留升级后新增的作品、额度和发送记录，不以恢复旧库覆盖新数据。关闭自主创作不会删除已有作品；管理员可在配置仍绑定原空间时查看历史，撤销委托后不能继续在普通私聊中读取其摘要。

## 群内收藏与分享

管理员选择群空间后，“自主分享权限”显示“仅收藏”或“可自主分享到原群”；私聊显示“私聊原授权”。允许不等于必发，MaiBot 仍独立决定是否分享，分享前还需原委托、预算和发送授权。实际发送结果继续在作品和任务记录中查看，许可显示不能作为 QQ 收图证据。

`autonomy.spaces[].group_inspiration` 控制群念头记录和新采用；独立的 `group_share_mode` 控制整个群空间的自主分享。默认 `collect_only` 只收藏，仍可在原授权内规划、生成、评审和细化。显式设为 `original_group` 才允许向绑定原群自主分享；关闭念头收集不会自动取消已成稿作品的分享许可。其他群成员不会因此获得命令或管理权限。

这项策略覆盖群空间内所有来源的自主作品，包括委托人聊天、无人时段和群念头。私聊和手动发送继续使用原授权及原发送记录规则；手动路径同样不能重发 `sending/send_unknown`。

Studio 只读兼容 schema 1..9。旧 schema 1..8 的已知群以及尚未建立新策略的群都显示“仅收藏”，不会推断旧群已获分享许可；升级后需管理员显式开启。当前页不修改配置、不写入策略、不清空额度或发送历史，也不向聊天摘要自动透传管理员群策略。

切换模式不能撤回已发送或已进入外部发送的图片。`sending/send_unknown` 继续保留且不可重发；恢复分享许可不重置累计额度，不自动重发旧图。2026-11-04 已完成 VPS 部署及在线只读查询验证；群行为使用隔离模拟，真实 QQ 群收图仍待验收，见[验收记录](group-inspiration-validation.md)。

## 如何验收

群空间的“创作念头”显示 MaiBot 通过群规划自选记录的主题、时间和采用状态，不显示参与人数或原文。“已采用（已立项）”附关联作品编号，表示计划已创建，绘图、评审及分享进展仍在对应作品中查看。模型可以不选择记录或暂不采用，所以没有记录不必然是故障；不进入规划的群发言可能被错过。旧“群灵感簿（实验）”保留读取，当前不接真实逐条收信。模拟验收和授权边界见[群灵感簿](group-inspiration.md)。

1. 在隔离的已授权空间模拟普通聊天与定时唤醒，观察是否能自主立项；模型也可以选择等待。
2. 用模拟绘图和视觉评审跑一幅作品，核对初稿、可选细化、最佳版本及分享回执；页面与聊天查询应对应同一作品。
3. 重复查询或刷新，确认没有新的模型规划、绘图或发送操作；查询其他人的作品不应泄露其状态。
4. 检查额度耗尽、未知回执、重载及旧档案迁移。新版本不会改写已冻结作品，也不会自动重发旧图。

具体测试证据见[验证记录](validation.md)。本地模拟与生产 QQ 实际收图分开记录。
