# 单作品群验收记录（0.12.0）

范围：纯插件实现；保留独立 MCP 与原 MaiBot，不清理旧任务、授权、发送记录或累计额度。目标群和部署快照仅保存在私有维护目录，不进入发行包。这里区分开发验证、部署观察和用户确认。

## 行为约束

- 对一个已核验的 QQ 群启用 `single_work`，永久锁定第一幅作品；初绘、对该初绘的编辑和分享各最多一次。
- 预留成功即占用该操作的一次机会；失败、拒绝或未知不会返还。请求幂等、原授权、每日预算和发送未知锁仍生效。
- 同一聊天流不能换空间、换委托人规避，手动画图/重发和旧命令发送也受限制。
- `paused=true` 只让目标空间待命，不撤销授权或修改旧计划；待命时没有该空间的工作线程、灵感接入和外部调用。
- `paused=false` 可能立刻触发无人唤醒。只有准备开始真实验收时才能解除；模型仍可等待、不采用念头、不细化或不分享。
- 配额是最多次数，不是成功保证。次数被失败或未知占用时，应核查原请求并结束本次验收，不能重建空间“补一次”。
